# Support

Avkroken använder olika GitHub-funktioner beroende på vilken typ av hjälp eller återkoppling som behövs.

## Frågor och hjälp

Använd Avkrokens GitHub Discussions för frågor om användning, arbetssätt eller sådant som ännu inte är ett konkret fel eller ändringsförslag.

## Fel

Använd GitHub Issues i det repository där problemet finns när du kan beskriva ett reproducerbart fel. Följ issue-mallen och ange så lite information som möjligt för att återskapa problemet.

## Förbättringar och idéer

Konkreta förbättringsförslag kan lämnas som issues i berört repository. Tidiga idéer och öppna resonemang hör hemma i Avkrokens Discussions.

## Säkerhetsproblem

Rapportera aldrig sårbarheter, tokens, privata nycklar eller andra känsliga uppgifter i publika issues, pull requests eller Discussions. Följ `SECURITY.md` i det berörda repositoryt och använd privat sårbarhetsrapportering när den finns.

## Bidrag

För kod- och dokumentationsändringar, följ `CONTRIBUTING.md` och repositoryts lokala instruktioner. Lokala regler har företräde framför denna gemensamma supportpolicy.

## Omfattning

Avkrokens projekt underhålls efter tillgänglig tid. En fråga eller rapport innebär därför inte någon garanterad svarstid, felsökning eller leverans av en viss ändring.
