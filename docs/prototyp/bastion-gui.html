bastion
Fristående SSH-klient — native på varje plattform, synk utan konto.
Prototyp Terminalen är simulerad — en webbsida kan inte öppna riktiga SSH-anslutningar. Kommandona svarar med samma data som panelerna visar. Prova help.

Native per plattform

SwiftUI på iOS/macOS, Kotlin på Android, WinUI 3 på Windows, GTK4 på Linux. Inget delat UI-lager — bara ett gemensamt synkprotokoll.

Synk utan inloggning

Värddatabasen slås ihop deterministiskt (last-write-wins + gravstenar) genom en fil i en mapp du redan synkar. Nyttolasten är AES-256-GCM-krypterad på enheten.

Öppen källkod

MIT-licens, ingen container, inget konto. Nycklarna lämnar aldrig enheten okrypterade.
